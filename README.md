# AD ASTRA

AD ASTRA is a browser-based narrative game about learning Latin while restoring a small base on Mars.

The current prototype contains a short opening chapter featuring CRAS, an eccentric robot companion, and a Latin-only base computer.

## Play

[Play the public prototype](https://ad-astra-mars-latin.alexyuan2017.chatgpt.site/)

## Development

Built with React, TypeScript, Vite, and Vinext.

```bash
npm install
npm run dev
```

Run the targeted tests with:

```bash
npm test
```

## Status

Early playable prototype. The project currently focuses on validating its opening narrative and core language interaction.
